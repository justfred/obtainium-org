The Newton as Journal

March 21, 2001.

Back to the Newton. For some reason or another — actually a combination — I’m back to using this wonderful device. If only someone could port Newton OS to the Palm platform. Although even then I wouldn’t be able to hook up to the Net as I have with this one just now, with the Ethernet card I’d been using in the 2400.

Another Newton demo. This fucker still rocks. In fact it basically outspecs anything else out there in almost all ways except color screen and MP3s. But the hidden part, the OS, was still what was really amazing about it. Here I am talking about that again.

Guess I should reccommend one of these on my website.

Maybe someday computers will be more like the Newton. But unfortunately the Assist function doesn’t work. Too bad one could not create a Newton-like shell for Unix. That would be the shit.
