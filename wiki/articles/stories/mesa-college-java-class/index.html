Mesa College, Java Class

February 2, 2004. Mesa College, San Diego›?.

It appears that I’m motivating. I made it down here in time to upgrade the memory on the iBook with something that actually works, and now I’m waiting for a Java or C/C++ class; I believe I might be better served by Java, we’ll see if I can get a reservation for the class; I guess I’ve also determined how the registration process goes.

Guess I should try to arrange classes later in the afternoon if possible, so I can at least make a pretense of working the morning. So this would be it.
